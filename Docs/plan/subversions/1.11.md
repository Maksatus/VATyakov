# 1.11 Bone с одной костью на вертекс

_Этап В — Bone, персонажи для толпы. Справочник — `Docs/plan/`, см. `README.md`._

**Входит:**
- `VatBoneEncoder` (§2.1): `_VatBoneTex` — (Δ, s) и q по кадрам, последняя строка — пивоты (§1.9);
- разложение skin-матрицы с проверками: `det B ≤ 0`, остаток `‖B − sR‖` и ошибка в мм;
- поле профиля Mode (Vertex / Bone); кость, которая не раскладывается, или блендшейп — весь ассет в Vertex с сообщением;
- индекс кости в TexCoord6 Float16 (§1.7, §1.9), SubGraph `vat_bone` и `vat_bone_blend`, графы `vat_lit_bone` и
  `vat_lit_bone_blend`; ключа `_VAT_BONES_1` нет (решение пользователя, выбор 1/2 influences — в 1.12);
- нормали и тангенты поворотом кости, баунды-капсулы (§1.8).

**Как проверить:** персонаж совпадает с SMR при Skin Weights = 1 Bone; клипы, VatAnimator и переходы работают без изменений (общее ядро); клип с неравномерным масштабом кости уходит в Vertex с сообщением.

**Тесты:** skin-матрица `diag(2, 1, 0.5)` уходит в Vertex; капсула содержит дугу при повороте от −30° до +90° за кадр; реконструкция против `BakeMesh` при `smr.quality = 1`.
