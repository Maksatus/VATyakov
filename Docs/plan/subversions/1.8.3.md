# 1.8.3 Позиции 8 бит по габаритам ассета

_Этап Б — рантайм, общий для всех режимов. Справочник — `Docs/plan/`, см. `README.md`._

Позиции занимают 8 из 12 байт на вертекс-кадр. Замеры после 1.8.2: 8 бит по габаритам ассета на глаз не отличить от
half, текстура позиций вдвое меньше, весь ассет — на треть (лук 4.76 → 3.17 МБ). Блочное сжатие (ASTC, ETC2) рвёт
тонкую геометрию — не используется. Решения пользователя: один габарит на ассет, формат выбирает бейкер по порогу из
профиля (по умолчанию 8 мм), размах — отдельное свойство `_VatPosScale`, шейдер один без веток и keyword.

**Входит:**
- Формат позиций ассета — `VatPositionFormat`: `Half` (RGBAHalf, как раньше) или `Byte` (RGBA8). У `Byte` смещение Δ
  хранится байтом на ось внутри габаритов Δ по всем кадрам ассета: `b = round((Δ − min) / size · 255)`, ось без движения
  (size = 0) — байт 0. `VatAsset` хранит формат и `VatPositionRange` (min, size); у `Half` min = 0, size = 1.
- Выбор при бейке: поле профиля **Max Position Error** (мм, по умолчанию 8, в хэше исходника). Бейкер считает
  максимальную ошибку `Byte` по всем вертексам и кадрам с учётом fp16-выборки (`t = half(b / 255)`) и печёт `Byte`, если
  она строго меньше порога; 0 — всегда `Half`. В логе и инспекторе ассета (карточка Precision, стат Positions) — формат,
  ошибка и ошибка `Byte`.
- Шейдер один: `pos = rest + _VatDrift.xyz + Δ_t · _VatPosScale.xyz`, Δ_t — смешанное значение текстуры. min прибавляет
  CPU: `VatAsset.Drift` возвращает d + min. Лишних операций нет: сложение заменилось на умножение-сложение.
  `_VatPosScale` — Per Material, Precision Single, по умолчанию (1, 1, 1, 0), пишет `ApplyTo`; вход `PosScale` у обеих
  функций позиции — последним.
- `formatVersion` 6. Оценка памяти в профиле — диапазон «8 бит – half», в ассете — по фактическому формату.
- VatDev перезапечь. Эксперименты со сжатием удалить: сцены `compression`, `compression_water`,
  `Assets/VatDev/Compression`, `Assets/VatDev/Shaders`, `VatDevLabel`.

**Как проверить:**
- лук в `compare` совпадает с SMR на Fire кадр 20, ассет лука — `Byte`, около 3.2 МБ;
- в инспекторе ассета видно формат, ошибку и ошибку 8 бит;
- толпа в `animator` и желе в `drift` (40 м) играют как раньше.

**Тесты:** выбор формата — малое движение даёт `Byte` с ошибкой в пределах порога, вертекс, улетевший на 10 м, —
`Half` и ошибку `Byte` больше порога; ось без движения — size 0 и нет NaN; порог 0 — `Half` даже без ошибки;
восстановление `rest + Drift + t · size` против источника в пределах заявленной точности; `Drift` прибавляет min;
`_VatPosScale` объявлен `float4` в обоих SubGraph и пишется в шаблон.
