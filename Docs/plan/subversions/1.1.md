# 1.1 Минимальная версия: позиции, один клип, ближайший кадр

_Этап А — Vertex-запечка. Справочник — `Docs/plan/`, см. `README.md`._

**Цель:** пройти весь путь «бейк → ассет → шейдер → телефон» на самом простом случае.

**Входит:**
- пакет и asmdef: Runtime, Editor, Tests (§4);
- `VatBakeProfile` с минимумом полей: префаб со SMR, один клип, fps;
- `SkinnedFrameSource`: копия для бейка, PlayableGraph с выключенными foot IK и root motion, `BakeMesh`, перевод в пространство корня префаба (§2.1). Анимация блендшейпов, если она есть в клипе, запекается сама через `BakeMesh`;
- `VertexEncoder`, только позиции: `_VatPosTex` RGBAHalf, offset от rest (§1.9, §2.2);
- меш с финальной раскладкой (§1.7), baseVertex = 0, баунды — объединение всех кадров (§1.8);
- `VatAssetWriter`: `.asset` с `[PreferBinarySerialization]`, повторный бейк на месте через `CopySerialized`, `formatVersion` (§1.8);
- `VatCore.hlsl`: адресация (§1.1), упаковка клипа (§1.4), индекс кадра loop с клампом (§1.3), без интерполяции (в 1.2 упаковка и время ушли на CPU, состояние — `_VatFrame`, §1.4);
- `VatShaderGraph.hlsl` с обёртками `_float`, SubGraph `VAT_Vertex` с Precision Single, только позиция;
- пример Unlit и материал-шаблон, в который бейкер пишет клип;
- сцена Compare: SMR и VAT рядом.

**Не входит:** интерполяция, нормали из анимации (свет идёт по нормалям покоя), несколько клипов, VatAnimator, переходы, Alembic, Bone.

**Как проверить:**
- в Compare VAT совпадает с SMR на кадрах бейка: при пошаговом проигрывании кадр в кадр;
- повторный бейк с другим fps: материал и префаб не теряют ссылки, в том числе после перезапуска редактора;
- на трёх устройствах, в Metal, Vulkan и GLES: персонаж анимируется и совпадает по форме с редактором, объект не Static.

**Тесты:** адресация и блоки ширины; кламп кадра на f ∈ {−1e-7, −kF, kF ± ulp} (с 1.2 — на CPU); раскладка меша совпадает с `VatLayout` (`GetVertexAttributes`, `GetVertexBufferStride`, round-trip вертексов, пока меш readable); бейк → перезагрузка → байты текстуры те же; повторный бейк сохраняет fileID; Half-родитель вызывает `_float`.

**Риски, которые закрывает:** Vertex ID и baseVertex на всех API, точность half через Shader Graph, формат меша и данные ассета в player-сборке.
