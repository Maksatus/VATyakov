# 1.8 Переходы: CrossFade и вес из кода

_Этап Б — рантайм, общий для всех режимов. Справочник — `Docs/plan/`, см. `README.md`._

**Входит:**
- `_VatFrameB` с весом, бленд двух клипов в шейдере с fallback'ами нормали и тангента (§1.5);
- `CrossFade(clip, d)`, `SetWeight(w, T)`, рампы веса на CPU;
- поведение при `CrossFade` посреди перехода и предупреждение в лог.

**Как проверить:** переходы плавные, без рывков; переходом можно управлять из скрипта через `SetWeight`; `CrossFade` посреди перехода пишет предупреждение.

**Тесты:** веса и рампы на CPU; `d ≤ 0` без NaN; противоположные N и T при весе 0.5 без NaN.
