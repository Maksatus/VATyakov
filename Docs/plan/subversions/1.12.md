# 1.12 Bone с двумя influences

_Этап В — Bone, персонажи для толпы. Справочник — `Docs/plan/`, см. `README.md`._

**Входит:** TexCoord6 UNorm8×4 с 16-битным весом (§1.9; TexCoord4 занят MotionVectors URP, UV в SubGraph идут через `half4` — байты это переживают, §1.7), выбор влияний как у Unity при Skin Weights = 2 Bones, нормализация (§1.7). Решения пользователя: шейдер один — всегда две кости на вертекс (однокостные `vat_bone*` из 1.11 переделаны, поля Skin Weights и ключа нет), до 256 костей.

**Как проверить:** совпадение с SMR при Skin Weights = 2 Bones; на трёх устройствах веса декодируются точно.

**Тесты:** против `BakeMesh` при `smr.quality = 2` по упакованному мешу — меньше 1 мм, в том числе при весе 0.5 и большом рычаге; при равных весах — как у Unity: первые два слота в порядке меша (план предполагал «меньший индекс», проба показала порядок слотов).
