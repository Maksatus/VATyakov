# 1.17 Тени

_Этап Д — оптимизация. Справочник — `Docs/plan/`, см. `README.md`._

**Входит:** opt-in ключи `_VAT_SHADOW_DOMINANT` и `_VAT_SHADOW_1INFL` через проверку `SHADERPASS == SHADERPASS_SHADOWCASTER` в Custom Function; рекомендация по прокси для теней — низкополигональный меш с ShadowsOnly (§3).
- `_VAT_SHADOW_DOMINANT` — во время перехода тень только от клипа с большим текущим весом (`w ≥ 0.5` — B, иначе A). Когда вес проходит 0.5, поза тени переключается за один кадр, поэтому ключ opt-in.

**Как проверить:** замер прохода тени на устройствах до и после; тень без заметных артефактов.
