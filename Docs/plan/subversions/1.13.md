# 1.13 Bone в игре: LOD, экипировка, скорость

_Этап В — Bone, персонажи для толпы. Справочник — `Docs/plan/`, см. `README.md`._

**Входит:**
- LOD-меши одного рига на общей bone-текстуре; bindposes проверяются на равенство;
- экипировка — меш, скиннённый на кость руки, со своим VAT-материалом (§1.6);
- `averageSpeed` и подгонка скорости проигрывания под скорость движения (§2.1).

**Как проверить:** LOD переключаются без скачка позы; оружие в руке не отстаёт; юнит идёт с заданной скоростью без скольжения ног.
