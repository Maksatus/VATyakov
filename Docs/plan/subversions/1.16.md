# 1.16 Rigid без xform-нод

_Этап Г — Rigid, разрушения. Справочник — `Docs/plan/`, см. `README.md`._

**Входит:** острова по связности, подгонка Kabsch, слияние островов с совпадающими (R, t), критерий — максимальная невязка ≤ 0.5 мм, отчёт об ошибке (§2.3).

**Как проверить:** экспорт Deform Geometry даёт тот же результат, что и Transform Geometry; экспорт с деформирующимися кусками даёт отчёт со списком островов.

**Тесты:** острова, разрезанные швами, сливаются; деформирующийся остров — ошибка с отчётом.
