# 1.14 Замер толпы и бюджеты

_Этап В — Bone, персонажи для толпы. Справочник — `Docs/plan/`, см. `README.md`._

Один замер вместо отдельных приёмки толпы и финальных бюджетов.

**Входит:**
- сцена `stress`: 100 юнитов со случайными клипами и переходами против 100 SMR с Mesh Deformation = GPU (Batched). Худший случай: все 100 юнитов делают `CrossFade` каждый кадр;
- замер на одном-двух устройствах, IL2CPP Release после прогрева:
  - CPU main и render thread, GPU на кадр, память;
  - «CPU на анимацию» — маркер `VatAnimator.Write` и события;
  - сравнение с SMR при том же качестве и тех же 2 influences;
- в отчёте — конфигурация: разрешение, вершин на юнит, число видимых юнитов, доля юнитов в переходе, каскады теней, MSAA, версии Unity и URP;
- документ с бюджетами для художников: вершин на юнит, каскадов, influences, мегабайт на ассет.

**Как проверить:** отчёт по замеру; Frame Debugger показывает SRP Batch во всех проходах. По результатам фиксируются критерий выигрыша (насколько VAT дешевле SMR) и бюджеты.
