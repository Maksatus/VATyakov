# 1.4 Alembic → Vertex (постоянная топология)

_Этап А — Vertex-запечка. Справочник — `Docs/plan/`, см. `README.md`._

**Входит:**
- asmdef `VATyakov.Editor.Alembic` с defineConstraints (§4);
- `VatAlembicFrameSource`: `UpdateImmediately(k / fps)`, корень плеера в identity, frameCount (§2.3);
- проверки топологии и соответствия вершин (§2.2), подсказка периода loop;
- пример `VAT_Lit_Vertex_Triplanar` для мешей без UV.

**Как проверить:** ткань или soft body из .abc выглядит так же, как в AlembicStreamPlayer; .abc с меняющейся топологией даёт понятную ошибку; пакет без установленного Alembic компилируется.

**Тесты:** VAT против кадров Alembic — ошибка в пределах квантования; переставленные вершины дают предупреждение; `Duration ≤ 0` — ошибка бейка.
